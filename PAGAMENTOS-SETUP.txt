CHECKOUTS $5/$10 + RECEBER EM STABLECOIN — SETUP
================================================
Páginas: /checkout-5.html (basic $5) e /checkout-10.html (premium $10).
Fluxo: nome+email (obrigatórios) -> /api/checkout salva venda pendente com UTMs+AB
-> redireciona p/ fatura NOWPayments -> webhook confirma -> /acesso.html libera
+ email (se RESEND configurado). Dashboard: /admin-vendas.html (Mine123).

PASSO 1A — NOWPayments (API gratuita, payouts em USDT etc.)
(cripto direto + cartão-via-parceiro; você sem KYC)
1. Crie conta em nowpayments.io (só email p/ começar, modo crypto).
ATENÇÃO: conta vendedor = CPF/CNPJ + banco (KYC total) e recebimento em REAIS.
Valores cobrados: basic R$ 27,90 / premium R$ 54,90 (ajuste mp_amount em worker.js
e os botões dos checkouts juntos).
1. developers.mercadopago.com > Suas integrações > Credenciais > PRODUÇÃO:
   copie o Access Token (NUNCA a public key para o backend).
2. Para testar sem gastar: use credenciais de TESTE + usuários de teste.
3. Webhook: o próprio worker cadastra notification_url
   (/api/webhook/mercadopago) em cada preference; ative "Notificações IPN/
   Webhooks" no painel se pedir. A confirmação é lendo o pagamento com seu
   token (não depende de segredo).
4. Worker secrets: MP_ACCESS_TOKEN = <access token produção> > Retry deployment.
5. Faça uma compra teste: botão "Pay with card" -> checkout MP -> pagando,
   volta p/ /acesso.html e a venda aparece paid no /admin-vendas.html.
Sem MP_ACCESS_TOKEN, o botão MP mostra "payments not configured" e o
botão crypto continua valendo se NOWPAYMENTS_API_KEY existir.

1. Crie conta em nowpayments.io (só email p/ começar, modo crypto).
2. Dashboard > API Keys > Create, copie a PUBLIC key (x-api-key).

   Depois: Deployments > Retry deployment.

PASSO 2 — Email de acesso (opcional, Resend tem plano gratuito)
1. resend.com > API Keys > crie uma key. 2. Worker secrets:
   RESEND_API_KEY = <key>  (+ RESEND_FROM se tiver domínio verificado,
   ex: "Access <access@seudominio.com>"). Sem isso, o acesso sai no
   /acesso.html e o dashboard mostra "failed:no RESEND_API_KEY".

PASSO 3 — Links de entrega
Edite ACCESS_LINKS no worker.js (basic/premium) com os links reais
dos episódios/catálogo, commit + push.

AVISO HONESTO (leia):
- NÃO existe processador legítimo de cartão→stablecoin "sem KYC":
  cartão exige KYC em algum ponto (bandeiras/leis AML). Quem prometer
  isso é golpe ou opera fora da lei.
- O que foi ligado: NOWPayments (conta só-email p/ crypto; payouts em
  stablecoin p/ sua carteira). Compras com CARTÃO via parceiros deles
  exigem verificação DO COMPRADOR — normal e legítimo.
- Alternativa 100% sem KYC de verdade: BTCPay Server auto-hospedado
  (grátis, open-source), porém só cripto (sem cartão).
- Vender p/ americanos pode gerar obrigação fiscal — fale com contador.
